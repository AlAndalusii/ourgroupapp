# Our Group App - Islamic Goals Tracker

A modern web application for tracking goals and self-improvement within a group context, built with Islamic principles in mind.

## Features

- **Clean, Luxury UI**: Modern design with attention to detail and visual appeal
- **Responsive Dashboard**: View and manage goals on any device
- **Multi-User Support**: Toggle between 3 user dashboards
- **Goal Management**:
  - Upload monthly and yearly goals
  - Rate/score monthly goals
  - View yearly goals in a clean layout
  - Track completed and missed goals
- **Progress Visualization**:
  - Line charts for month-to-month performance
  - Bar charts for goal completion
  - Pie charts for overall progress
  - Radar charts for strengths and weaknesses
- **Personal Growth**: Track improvements and identify areas for development

## Technology Stack

- Next.js 14+ (React Framework)
- TypeScript (Type-safe JavaScript)
- Tailwind CSS (Utility-first CSS framework)
- Chart.js (Data visualization)

## Getting Started

### Prerequisites

- Node.js 18.17.0 or later
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/ourgroupapp.git
   cd ourgroupapp
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Application Structure

- `/src/app`: Next.js app directory structure
- `/src/components`: Reusable React components
- `/src/styles`: Global styles and Tailwind configuration
- `/src/lib`: Utility functions and shared logic

## Usage

1. **Home Page**: Introduction to the app and Islamic principles
2. **Dashboard**: Access your personal dashboard
   - View the overview of your progress
   - See yearly and monthly goals
   - Track your progress over time
   - Add new goals

3. **User Switching**: Toggle between different users to view their dashboards

## Customization

The app is designed to be easily customizable:

- **Color Scheme**: Edit the Tailwind configuration to match your preferred colors
- **User Names**: Modify the user data in the dashboard component
- **Goals**: Update the sample goals or connect to a real database

## Islamic Principles

The app is built with these Islamic principles in mind:

1. **Consistency in Good Deeds**: "The most beloved of deeds to Allah are those that are most consistent, even if they are small." (Bukhari and Muslim)

2. **Continuous Improvement**: "Whoever institutes a good practice that is followed after him, will have a reward similar to that of those who follow it." (Muslim)

3. **Self-Accountability**: "Hold yourself accountable before you are held accountable, and weigh your deeds before they are weighed." (Tirmidhi)
